# Radial-Wheel-Viewpoint

Frees the mouse cursor while radial menus are open and restores Viewpoint cursor control when they close.

Requires Viewpoint and ZombieBuddy.
Tested on PZ 42.21; newer versions are unconfirmed.
Release-to-select is not guaranteed.
Extract the ZIP’s RadialWheelViewpoint folder into your Zomboid/mods folder, then enable Radial Wheel Viewpoint.
AI disclosure: Built with AI-assisted coding and tested by me in-game.
